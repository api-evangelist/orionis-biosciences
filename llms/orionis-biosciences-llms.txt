# Orionis Biosciences

> Orionis Biosciences is a privately held biotechnology company in Waltham, Massachusetts, with a
> research site in Ghent, Belgium, developing precision medicines across molecular glues
> (Allo-Glue), conditional and cis-targeted cytokines (A-Kine) and multi-specific cell engagers
> (MCE). Orionis publishes no developer program and no product API. The only machine-readable
> surface on orionisbio.com is the WordPress REST API (wp/v2), which serves the company newsroom,
> corporate and platform pages, leadership profiles and the media library as anonymously readable
> JSON.

This llms.txt was GENERATED by API Evangelist from the public orionisbio.com surface and the
artifacts in this repository. Orionis Biosciences does not publish an llms.txt of its own
(https://orionisbio.com/llms.txt returns 404).

## APIs

- [Website Content API (WordPress REST wp/v2)](https://orionisbio.com/wp-json/wp/v2): Anonymous read
  API over orionisbio.com content — 22 news posts, 16 corporate/platform pages, 15 `orionis_team`
  leadership profiles, 208 media items, 5 category terms, plus discovery and site-search endpoints.
  Pagination via `page`/`per_page`; totals in `X-WP-Total` and `X-WP-TotalPages`. No credentials
  required to read; writes require WordPress Application Password authentication.

## Key endpoints

- `GET https://orionisbio.com/wp-json/` — route discovery index (all registered namespaces)
- `GET https://orionisbio.com/wp-json/wp/v2/posts` — company news posts
- `GET https://orionisbio.com/wp-json/wp/v2/pages` — corporate and platform pages
- `GET https://orionisbio.com/wp-json/wp/v2/orionis_team` — leadership and scientific-team profiles
- `GET https://orionisbio.com/wp-json/wp/v2/media` — media library
- `GET https://orionisbio.com/wp-json/wp/v2/categories` — category taxonomy terms
- `GET https://orionisbio.com/wp-json/wp/v2/search?search=<term>` — site-wide search

## Not available

- No developer portal, API reference, sandbox, API keys, pricing or sign-up — Orionis Biosciences
  runs no developer program.
- No SDKs or client libraries in any public package registry.
- No MCP server: `/wp-json/mcp`, `/mcp` and `/sse` all return 404. The `wp-abilities/v1` registry
  (the surface a WordPress MCP adapter would expose) is registered on this host but returns
  HTTP 401 `rest_forbidden` anonymously.
- No A2A agent card at `/.well-known/agent-card.json` or `/.well-known/agent.json` (both 404).
- No security.txt, no status page, no changelog, no deprecation policy, no webhook or event surface.
